# Design System & Implementation Summary

## Visual World: The Signal Bench

The showcase website for **Electromagnetic Lift-Assisted Transport** is designed around *The Signal Bench* concept:
- **Materiality:** Deep instrument glass (`#080d08`), etched graticule division grids (`#1a271a`), and subtle illuminated phosphor glow effects.
- **Color Palette:**
  - Phosphor Green (`#00e060`): Traces, key highlights, primary typography, winner selections.
  - Signal Amber (`#ffb830`): Telemetry readouts, pending validation statuses, warnings, secondary figures.
  - Graticule Gray & Low Green: Etched grid lines, coordinate references, secondary captions.
- **Typography:**
  - Display: `Orbitron` — Condensed technical instrument character.
  - Body: `Source Sans 3` — High legibility workhorse for technical narrative.
  - Monospace: `Source Code Pro` — Data tables, test IDs, mathematical formulations, coordinates.

## Key Sections & Structural Integrity

1. **Hero:** Restrained typography, 3m track progress sweep, background technical video with poster fallback, and four key figures.
2. **Problem & Context:** Technical rationale for contactless electromagnetic lift-assisted linear transport.
3. **Architecture Selection:** 4 concepts compared with prominent scoring cards (Winning concept scored 73 pts) plus an expandable matrix.
4. **Electromagnetics:** Core geometry selection (C-Core vs E-Core trade-off story), pull force equation, and SVG parametric sweep chart showing 24 V satisfaction.
5. **System Design:** Custom vector block diagram illustrating power distribution, STM32 control loops, and coil stages, accompanied by mechanical/firmware breakdown and lean prototype budget (INR 5,750).
6. **Validation Plan:** 3-metre track graphic marking Points A, B, and C with four distinct test cases (TC-AMF-001 through TC-AMF-004) labeled explicitly as **Pending / Planned**.
7. **Timeline:** Four active workstreams with unvarnished task-level statuses (`Completed`, `In Progress`, `Stuck`, `Yet to Start`).
8. **Media Gallery:** Responsive grid of CAD animations and laboratory test runs with factual captions.
9. **Team:** Five cards with clean monogram badges and verified engineering domains.
10. **Footer:** Project credentials, contributor listing, and system status indicator.
